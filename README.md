# Dead by Daylight Randomizer
A Dead by Daylight (DBD) Randomizer tool currently in development for Windows. This application will allow players to generate random perks, items, and loadouts to make their DBD experience more unpredictable and fun.

Features (planned):

Random perks for Survivors and Killers

Random item and add-on selection

Easy-to-use interface on Windows

Lightweight and fast

🚧 Status: Under development – deployment coming soon.
